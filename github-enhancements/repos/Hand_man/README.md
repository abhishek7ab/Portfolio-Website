## 🎮 How to Play

1. The game selects a random sport category word (e.g., Tennis, Cricket, Football, Badminton, Rugby, Baseball, Kabaddi).
2. Guess letter-by-letter to reveal the secret word.
3. Every incorrect guess draws a segment of the Hangman ASCII figure.
4. Guess all characters before running out of lives to claim victory!

```text
       ------
       |    |
       |    O
       |   /|\
       |   / \
       |
```

## 🚀 Quick Run

### Prerequisites
- Python 3 installed. No external packages required!

### Run directly:
```bash
git clone https://github.com/abhishek7ab/Hand_man.git
cd Hand_man
python handman.py
```
