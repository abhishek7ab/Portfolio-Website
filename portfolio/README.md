# 💼 Portfolio Next.js Application

This is the Next.js frontend application for Abhishek Badave's developer portfolio, built with Next.js 16 (App Router), TypeScript, and Tailwind CSS.

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can edit the page content by modifying components in `src/components/` and data in `src/data/`.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org) (App Router & Turbopack)
- **Styling**: [Tailwind CSS](https://tailwindcss.com)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: React Icons
- **Theming**: `next-themes`
- **Validation**: Zod + React Hook Form

## 📦 Build for Production

```bash
npm run build
npm start
```
