## 🌸 Key Features

- **🌱 Plant Catalog & Filtration**: Browse plants by sunlight needs (Low, Medium, Bright), watering frequency, pet-friendliness, and size.
- **🪴 Smart Plant Care Guides**: Detailed watering, humidity, and soil recommendations on each plant product page.
- **🛒 Dynamic Cart & State**: Persistent shopping cart with quantity adjustments and coupon code support.
- **📱 Responsive Botanical UI**: Mobile-optimized, nature-inspired green palette with clean product carousels.

---

## 🛠️ Tech Stack

- **Frontend**: React.js / HTML5 / Modern CSS
- **Styling**: Tailwind CSS
- **Icons**: Lucide Icons
- **Deployment**: Vercel / Netlify

---

## 🚀 Quick Setup

```bash
# Clone the repository
git clone https://github.com/abhishek7ab/BloomCart-Online-Plant-Shop.git
cd BloomCart-Online-Plant-Shop

# Install dependencies
npm install

# Start local development server
npm run dev
```
